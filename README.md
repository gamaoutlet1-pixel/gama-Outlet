# Gama Outlet

Sistema próprio de gestão da Gama Outlet.

## Objetivo
Aplicativo Windows com produtos/estoque, precificação, PDV, histórico detalhado de vendas, relatórios, usuários/permissões e atualização automática.

## Desenvolvimento
A aplicação é empacotada como desktop Windows usando Electron. O workflow de CI prepara a build do Windows no GitHub Actions.
